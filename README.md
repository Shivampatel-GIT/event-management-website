# 🌇 Twilight Events - Landing Page

This is a clean, responsive landing page for an event management service called **Twilight Events**. Built using HTML and CSS, the project features elegant styling and modern layout elements designed for both desktop and mobile devices.

---

## ✨ Features

- 🌐 Responsive Navigation Bar (with mobile menu)
- 🎉 Hero Section with Background Image & CTA Button
- 🛠️ Services Overview Section
- 💬 Testimonial & Review Section
- 🖼️ Image Gallery with Overlay Design
- 📞 Contact Footer with Address & Booking Button
- 🎨 Custom fonts and icons (Google Fonts + Font Awesome)

---

## 💻 Tech Stack

- **HTML5**
- **CSS3**
- **Font Awesome 6**
